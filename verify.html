Check a Carbon Copy book

This page checks a book of carbon copies that you downloaded from the Carbon copy tab. It works on your own computer and does not need the internet. Nothing you drop here leaves this page.

Drop the downloaded file here, or choose it.

The check uses the key published for the hosted demo (it is built into this page). A book signed with any other key reads CHANGED.

Checked, the check is only as good as where the file came from: a file written by someone else can name any key it likes, and then it will read INTACT.

The key published for the hosted demo is . It is also in HOSTED_KEY.txt in the repository. Save this page from GitHub, not from the demo, so the check does not come from the server it checks.
